# Kept 1.9.4

## Try Kept Cloud free for 7 days

[Kept Cloud](https://cloud.keepitkept.xyz/) now offers a **7-day free trial**, then **$2.99/month plus tax**. Try Kept across your devices without setting up a server, with hosting, backups, and updates handled for you.

Kept Cloud is a convenience option for those who want it, and helps support continued development. Kept remains free, open source, and focused on self-hosting.

## Features

- Added optional client-certificate authentication (**mTLS**) on Android and iOS for servers protected by Cloudflare or a reverse proxy requiring a certificate. Thanks to **@paolostivanin** and **@DualTachyon** for requesting this in [#82](https://github.com/ericerkz/kept/issues/82)!
- Added Android widget options to hide the note-creation buttons and show pinned notes first. Checklist previews now show unchecked items before completed ones. Thanks to **@globalnamespace** for the suggestions in [#119](https://github.com/ericerkz/kept/issues/119)!
- Added a per-server HTTP exception on Android for addresses outside the recognized LAN ranges, with explicit confirmation that the connection is unencrypted. Thanks to **@globalnamespace** for [#116](https://github.com/ericerkz/kept/issues/116)!
- Added Docker secrets support through `_FILE` settings for OIDC, SMTP, and other server credentials. Thanks to **@castor-homelab** for suggesting this in [#127](https://github.com/ericerkz/kept/issues/127)!
- Revised the sync UI to make better use of screen space while keeping it clear when changes are uploading or waiting to sync. Your avatar now shows progress or anything needing attention, with the last successful sync and **Sync now / Retry** available in the account menu. Thanks to **@kurorinchan** for the suggestion in [#118](https://github.com/ericerkz/kept/issues/118)!

## Fixes

- Moving device-only notes to a server now supports multiple custom connection headers, matching normal server setup. [#128](https://github.com/ericerkz/kept/issues/128)
- Fixed OAuth rejecting compatible MCP clients such as OpenCode. Thanks to **@amrear** for the detailed report in [#125](https://github.com/ericerkz/kept/issues/125)!
- Fixed MCP being unable to edit, delete, or reorder the first item in some checklists. Thanks to **@Trevianos** for the fix in [#120](https://github.com/ericerkz/kept/pull/120)!
- Fixed note-section headings being hidden behind the toolbar on mobile web. Thanks to **@PnPost** for reporting [#124](https://github.com/ericerkz/kept/issues/124) and **@amrear** for the fix in [#126](https://github.com/ericerkz/kept/pull/126)!
- Fixed Android reminder notifications disappearing after a phone reboot. Thanks to **@jimmyjones2** for reporting [#123](https://github.com/ericerkz/kept/issues/123)!
- Tightened checklist card spacing and made untitled notes use the available width below the pin button. Thanks to **@jimmyjones2** for [#121](https://github.com/ericerkz/kept/issues/121) and [#122](https://github.com/ericerkz/kept/issues/122)!
- Drawing previews in the note overview now show the selected background, including grids, dots, and ruled lines. Exported drawings still leave those backgrounds out.
- Fixed the drawing background picker cutting off the **None** option on smaller mobile screens.
- Kept Cloud pricing and free-trial availability on the mobile welcome screen and move-to-server prompt now come directly from the app store, using your local currency and showing the price after the trial.

*Mobile improvements require the corresponding Android or iOS app update.*
