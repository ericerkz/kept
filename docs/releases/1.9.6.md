# Kept 1.9.6

## Features

- **More flexible checklists!** Mix text and multiple checklists within the same note. Insert a checklist from the toolbar, tap above or below it to add text, or press Enter on an empty checklist row to continue writing normally.
- **Patterns and highlights:** Choose from 27 repeating background patterns, including lemons, cherries, hearts and roses. Patterns follow your note’s colour, and text highlighting automatically picks a complementary shade.
- **Updated image previews:** Photos now use compact layouts and **+N images** indicators to stop image-heavy notes taking over the overview. Opening a note preserves its full layout, with images in their original positions within the text.
- **Hebrew is now available! 🌍** Kept’s first community translation is here. Thanks to **@zombie241088** for contributing [#146](https://github.com/ericerkz/kept/pull/146)!
- **Default note colour:** Choose the starting colour for new notes under **Settings → Display & Editing**. Thanks to **@Stephane-30** for suggesting this in [#159](https://github.com/ericerkz/kept/issues/159)!
- **Creation-date searches:** Use `!date` with years, months, specific dates, weekdays, today or yesterday. The Filters menu includes clickable examples, and ordinary years remain searchable as note text.
- **Select all:** Select every note in the current view from the selection toolbar. On narrow phones, this lives in the **More** menu to keep the toolbar on one row.
- Added adjustable eraser sizes in the drawing editor.
- Added edited timestamps to desktop notes, with the creation date available on hover or click. Mobile timestamps can now reveal the creation date too.
- Android now supports servers using a CA certificate you’ve installed on your device. Thanks to **@arasadnarim** for [#139](https://github.com/ericerkz/kept/issues/139)!
- Added an optional Docker configuration to start the container entirely as a non-root user, with setup instructions. The default configuration is unchanged. Thanks to **@Splinter7914** for [#80](https://github.com/ericerkz/kept/issues/80)!

## Fixes

- Fixed note content disappearing when switching checklist modes, with improved undo handling. Thanks to **@B85S5DSG** for reporting [#141](https://github.com/ericerkz/kept/issues/141)!
- Made deleting large selections much faster, and corrected bulk unarchive, permanent deletion and undo behaviour.
- Fixed drawing notes missing **Delete note** in their menu. Thanks to **@Ancalagonn** for [#144](https://github.com/ericerkz/kept/issues/144)!
- Fixed starting a new drawing from an existing drawing note, preserving the current note and keeping the new editor properly positioned.
- Fixed drawing menus and tool palettes being cut off on narrow screens.
- Fixed cleared new-note drafts leaving empty notes behind or reappearing after queued saves.
- Fixed newly created notes briefly showing **Unshare with me** instead of **Delete note**.
- Fixed image-only and link-only notes not supporting long-press selection and dragging on mobile.
- Removed the extra wait when pressing Back after editing a note on mobile. Notes are saved safely on-device before closing, with follow-up work continuing in the background.
- Improved checklist preview spacing and font consistency across density settings. Thanks to **@jimmyjones2** for [#147](https://github.com/ericerkz/kept/issues/147)!
- Fixed overview cards shifting off-screen in large libraries, including Google Keep imports, at some foldable resolutions.
- Improved Android tablet layouts and kept Smart Capture compact on foldables.
- Corrected right-to-left text handling while keeping navigation, toolbars and the overall layout in their usual positions.
- Fixed the cursor starting on an extra line when reopening notes, improved Unicode searches, and corrected patch-release update detection.
- Removed the duplicate **Users** shortcut from the top bar; user management remains accessible from the sidebar.
- Fixed transparency around the README logo images.

Thanks to **@amrear** for the contributions across search, selection, bulk actions, navigation, drawings, draft handling and README improvements!

*Mobile improvements require the corresponding Android or iOS app update.*
