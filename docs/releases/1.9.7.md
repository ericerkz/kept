# Kept 1.9.7

## Features

- **Code blocks are here!** Keep code snippets alongside your notes, with syntax highlighting, automatic language detection, a language selector and quick copying. Add a code block from the formatting menu or use triple backticks. Thanks to **@inject3d** for suggesting [#168](https://github.com/ericerkz/kept/issues/168)!
- **German is now available! 🌍** Thanks to **@SvenPausH** for contributing the translation in [#166](https://github.com/ericerkz/kept/pull/166)!
- **Sort checklists A→Z:** Alphabetically sort a checklist while keeping nested items with their parents. Manual reordering and undo still work afterwards. Thanks to **@wimvanhooff** for suggesting [#143](https://github.com/ericerkz/kept/issues/143) and **@Mittalnew** for contributing [#163](https://github.com/ericerkz/kept/pull/163)!
- **Expanded MCP support:** Connected assistants can now work with note colours, backgrounds, repeating patterns, highlights, drawings and multiple checklists.

## Fixes

- Improved saving, archiving and synchronization in large libraries, especially after Google Keep imports. Reduced unnecessary data transfers and processing of unchanged notes. Thanks to **@bperry** for the detailed report in [#170](https://github.com/ericerkz/kept/issues/170)!
- Made ordinary note reordering faster, using smaller position updates while keeping the order consistent across devices.
- Improved responsiveness when indenting large checklists. Thanks to **@inject3d** for reporting [#167](https://github.com/ericerkz/kept/issues/167)!
- Improved text selection and formatting, including selecting backwards, keeping the floating toolbar within the screen, and keeping the mobile keyboard open when applying formatting.
- Fixed an image-processing dependency preventing startup on some older CPUs, including affected TrueNAS installations. Thanks to **@ih8legal** for reporting [#169](https://github.com/ericerkz/kept/issues/169)!

*Mobile improvements require the corresponding Android or iOS app update.*
