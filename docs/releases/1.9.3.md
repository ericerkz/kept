# Kept 1.9.3

### Introducing Kept Cloud

I’m excited to share [Kept Cloud](https://cloud.keepitkept.xyz/)! A number of people have asked for a way to use Kept across their devices without setting up and maintaining a server, and now there’s an option for that.

You get your own private Kept server with hosting, backups, and updates handled for you. Use it on iOS, Android, and the web, and add family, friends, or teammates under one subscription, with no per-user charge.

Kept remains free, open source, and focused on self-hosting. Cloud runs the same Kept you can host yourself, with no exclusive features. Kept Cloud is a convenience option for those who want it, and helps support continued development.

### Features

- Swipe left or right on a note to archive it on touch devices.
- Choose whether shared notes inherit the owner’s labels and binders, or organize them yourself. Thanks to **@davetansley** for suggesting optional label inheritance in [#43](https://github.com/ericerkz/kept/issues/43#issuecomment-5525110816).
- Full server backups, including all accounts, notes, images, and attachments, with restore support during setup.
- Increased image and attachment upload limits to **100 MiB per file**.
- Kept Cloud sign-up from the mobile welcome screen, and a choice between Cloud and self-hosting when moving device-only notes to a server.

### Fixes

- Improved photo uploads on iOS and Android, including HEIC, Live Photos, Motion Photos, and photos shared into Kept.
- Fixed unrelated labels sometimes being added when opening an existing note on mobile.
- Improved mobile sync stability and recovery from interrupted transfers.
- Uploads blocked by full server storage now show a clear message and allow other changes to keep syncing.
- Fixed calendar subscription links and the Google Calendar setup URL pointing to the app’s local address instead of the server.
- Improved mobile and foldable welcome-screen layouts.

### Security

- Fixed a database transaction issue where a failed import could roll back unrelated note saves.
- Fixed malformed note content causing note lists or synchronization to fail.
- Fixed removed collaborators being able to regain access through an old rejoin permission.
- Strengthened storage quota enforcement, remote MCP file-download protections, and request limits.
- Updated dependencies with security fixes.

*Mobile improvements require the corresponding iOS or Android app update.*
