# Kept 1.9.8

## Features

- **Encrypted locked notes:** Newly locked notes now encrypt their text, checklists, images and attachments on your device before syncing. Titles and basic note metadata remain visible. Existing locked notes keep their current behavior until you change their passcode. Thanks to **@tsfxpro** for suggesting this way back in [#27](https://github.com/ericerkz/kept/issues/27).
- Unlocked encrypted notes show their content and images in the overview, then hide again when the unlock window expires. Previously loaded link previews are preserved securely without automatically fetching previews for links inside encrypted notes.
- **More control over backups:** Keep everything, retain a set number of backups, delete older backups, or use a daily/weekly/monthly/yearly retention schedule. The default remains keeping everything. Thanks to **@macros111** for the suggestion in [#171](https://github.com/ericerkz/kept/issues/171).
- **Better checklist controls:** Each checklist now has its own menu for sorting, unchecking items, deleting completed items, converting to text, or removing the whole list. Removal shows how many items it affects and offers Undo. The menus support keyboard navigation too.
- **Faster desktop note capture:** Press **Ctrl+Enter**, or **⌘+Enter on Mac**, to save your note and start another. Thanks to **@jtagcat** for suggesting this in [#179](https://github.com/ericerkz/kept/issues/179).
- **Polish translation:** Thanks to **@pawel112** for contributing [#177](https://github.com/ericerkz/kept/pull/177).

## Fixes

- Empty checklists can now be removed with **Backspace or Delete**, and whole checklists can be removed from the toolbar or their own menu. Surrounding text is preserved, and Undo restores the list. Thanks to **@spacecarsla** for [#173](https://github.com/ericerkz/kept/issues/173).
- Fixed leaving a shared note getting stuck in the sync queue and preventing other changes from syncing. Thanks to **@judwhiteneck** for [#176](https://github.com/ericerkz/kept/issues/176).
- Fixed checklist spacing jumping when the keyboard opens on Android.
- Improved handling of large Takeout uploads and server restores, with longer upload windows and clearer reporting when an upload is interrupted.
- Filled in missing Hebrew translations and improved wording. Thanks to **@zombie241088** for [#175](https://github.com/ericerkz/kept/pull/175).

## Security

- Bundled notification messages locally, removing an external dependency.
- Tightened anonymous request-size limits while preserving support for larger authenticated note updates.
- Added safeguards around encrypted-note syncing, passcode changes and lock removal so interrupted operations preserve the saved note and its files.

## Other updates

- Added an expandable web keyboard-shortcuts reference to the README’s technical documentation.
- Refreshed the README and website imagery to better show Kept’s notes, drawings, checklists and other features.

**Please update your mobile apps before using encrypted notes. Older apps cannot open them; the updated web app can.**
